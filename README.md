# Ocean Shallows

**▶ 在线演示（点击直接打开页面）：[https://yinyuejzzj.github.io/ocean-shallows-webgl/](https://yinyuejzzj.github.io/ocean-shallows-webgl/)**

**源码仓库：** [https://github.com/yinyuejzzj/ocean-shallows-webgl](https://github.com/yinyuejzzj/ocean-shallows-webgl)

一个单文件的 Three.js r128 WebGL 热带浅海场景。俯视视角，海水铺满屏幕，左上角是一小段弯曲的沙滩。没有构建步骤、没有 npm 依赖；全部场景实现集中在 `ocean-shallows.html` 一个文件里，`index.html` 只是让 Pages 根路径可用的跳转页。

---

## 打开方式

| 方式 | 做法 |
| --- | --- |
| 在线 | 点顶部的演示链接（由 GitHub Pages 托管） |
| 本地 | 直接双击 `ocean-shallows.html`，或在目录里运行 `python -m http.server` 后访问 |

页面通过 cdnjs 加载 Three.js r128、通过 Google Fonts 加载 Fraunces 与 Nunito Sans，**需要联网**。断网会显示加载失败提示。要完全离线，把 `three.min.js`（约 603 KB）内嵌进 HTML，并去掉字体外链（会退回系统字体）。

## 场景内容

- **水面**：GPU 高度场涟漪模拟，屏幕边缘阻尼带吸收波纹（不反射）；折射、流动焦散、朝岸滚动的长涌浪、细碎阳光闪烁；按水深从浅松石绿渐变到深蓝宝石色；浪在沙滩上破碎成带泡沫的冲流与蕾丝状泡沫，回退后留下光泽湿沙；摇曳的棕榈树影投在沙滩与浅水区。
- **海床（预烘焙）**：带波纹的沙地、海草草甸、珊瑚头与礁石（含接触阴影）、珊瑚碎石、海星、贝壳、海胆。
- **生物**：蝠鲼（Manta）、斑点鹞鲼（Spotted Eagle Ray）、蓝斑魟（Blue-spotted Stingray）、海月水母（Moon Jelly）、太平洋黄金水母（Sea Nettle）。鳐鱼双层片体、拍鳍或波浪式起伏、转弯侧倾、沙地投影、尾迹、跃水翻转、趴沙休息与受惊扬沙；水母伞盖脉动推进、菲涅尔半透明、随洋流漂移并被漩涡吸引、camera-facing 触手与口腕条带、提到空中时滴水。
- **界面**：磨砂玻璃 dock 放 5 张卡片，缩略图由同一套 3D 模型离屏渲染生成；中英切换；生物计数器（`4 rays · 5 jellies`）；上限 48 只；响应式布局；按帧率自适应画质。

## 操作

| 操作 | 效果 |
| --- | --- |
| 点击卡片 | 生物沿抛物线被扔进海里，带水花、波纹圈与飞溅水滴 |
| 拖动卡片 | 把生物悬停在水面上方，松手放到任意位置 |
| 点击水中的生物 | 惊走鳐鱼；魟鱼受惊时扬起泥沙 |
| 拖动 Whirlpool 圆环 | 改变漩涡位置 |
| 右上角 `EN` / `中` | 切换界面语言 |

按钮与快捷键：

| 按钮 | 快捷键 | 作用 |
| --- | --- | --- |
| Rain | `R` | 下雨（雨滴注入涟漪） |
| Whirlpool | `W` | 开关漩涡 |
| Calm | `C` | 平静模式 |
| Clear sea | `X` | 清空海洋 |
| Sound | `M` | 合成海浪声、水花与叮咚声 |
| Hide UI | `H` | 隐藏 / 显示界面 |
| EN / 中 | `L` | 切换中英文 |

## 实现要点

- 水面是 256² 的 ping-pong 高度场，使用半浮点渲染目标（不支持时退回 8 位）；脉冲批量注入，边缘阻尼带吸收。
- 海床一次性烘焙到 1024² 渲染目标，运行时只采样，不逐帧重绘细节。
- 生物用 `InstancedBufferGeometry` 批量绘制；实例化参数打包成 vec4，以避开 WebGL 顶点属性数量上限。
- 5 张 dock 缩略图是离屏 `WebGLRenderer` 真实渲染的 PNG，不是贴图或占位图。
- 画质自适应会调整 DPR、焦散层数与粒子数量。

## 已知边界

这些是程序化近似，不是物理仿真或外部模型：

- 水面涟漪是高度场近似，吸收边界靠阻尼带而非完美无反射；焦散是程序化噪声。
- 棕榈只有程序化影子，没有 3D 树体；生物是程序化网格，没有加载外部 `.glb`。
- 声音是 Web Audio 合成，浏览器要求先有用户交互才能播放。
- 需要 WebGL 与浮点 / 半浮点纹理能力；老设备会降级画质或加载失败。48 只生物加全屏片元着色器在集显和手机上会触发降档，属预期行为。
